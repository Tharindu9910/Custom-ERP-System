POST /api/v1/users/profile/complete First-login atomic insert across 4 tables
Creates rows in user_profiles + user_preferences + user_onboarding + user_wallets in one transaction. Returns 201 first time, 409 if profile already exists. Uses the access_token from the Token Store.

GET /api/v1/users/me profile + preferences + onboarding + wallet
Single round trip for app launch. wallet.tier + onboarding.tier are derived from wallet.lifetime_earned per A16. Returns 404 if profile not yet complete, 410 if soft-deleted.

GET /api/v1/instrument/next Returns next unanswered foundation question + session_id. Auto-fills Respond panel.
Requires Authorization: Bearer <access_token>.
Returns { session_id, question: {...} } or { session_id, question: null } when all questions answered.
On success, session_id + question fields are auto-saved and the Respond panel is pre-filled.
RESPONSE
—
POST /api/v1/instrument/respond Submit an answer. Call /next first to auto-fill session_id + question_id.
Idempotent: re-submitting the same question_id updates the existing row — never duplicates.
✓ Auto-filled from last /next response

—
GET /api/v1/instrument/progress How many foundation questions answered vs total.
